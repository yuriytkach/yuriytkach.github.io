Privacy Policy

For YouTube Channel Agent. Last updated 10 October 2026.

YouTube Channel Agent is a personal tool. Only I, Yuriy Tkach, use it, to manage my own YouTube channels: updating video titles, descriptions, tags and subtitles, and reading channel analytics. It is not offered to anyone else.

What it accesses

With my permission, through Google sign-in, it uses the YouTube Data API and the YouTube Analytics API to read and edit my own channels' videos and statistics.

Where data goes

Everything stays on my own computer. The sign-in token is stored locally and is never shared. No data is sold, shared with third parties or used for advertising.

Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
